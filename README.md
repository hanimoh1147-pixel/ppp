# Hani Unlocker prototype

Responsive Arabic-first website with separate pages for JTAG, FRP, MDM, iCloud, network unlock, and software/repair. Includes account, orders, top-up, support and terms pages.

Important: visual prototype only. Forms do not save data, prices are not live, and wallet balance is not active. Production requires Supabase Auth, PostgreSQL, RLS, private receipt storage, and secure database functions for wallet operations. Never expose the Supabase service-role key in browser code.
